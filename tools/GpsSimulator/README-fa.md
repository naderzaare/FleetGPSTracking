# فرم شبیه‌ساز GPS روی Windows

Python 3 با Tkinter لازم است؛ نصب معمول Python برای Windows آن را دارد. بسته pip، Python روی Ubuntu یا تغییر ایمیج Docker لازم نیست.

در PowerShell:

```powershell
cd C:\Projects\FleetGPSTracking\FleetGPSTracking
py -3 tools/GpsSimulator/gui.py
```

- آدرس سرور: برای VirtualBox با NAT و انتقال پورت فعلی، `127.0.0.1` بماند؛ برای سرور دیگر، IP یا DNS قابل دسترس آن را وارد کنید.
- پورت: `5027`.
- تعداد دستگاه: از ۱ تا ۱۰۰. هر دستگاه اتصال TCP و شناسه ساختگی جدا دارد؛ این سقف ابزار تست است و تضمین ظرفیت سرویس نیست.
- فاصله ارسال: از ۰٫۱ تا ۳۶۰۰ ثانیه برای هر دستگاه، پس از ACK قبلی. ارسال اولیه هر دستگاه بلافاصله انجام می‌شود.
- «شروع»: اتصال و ارسال تکراری تا زمان توقف.
- «اعمال تغییرات»: تعداد دستگاه و فاصله ارسال را در حین اجرا تغییر می‌دهد. برای تغییر سرور یا پورت، ابتدا توقف کنید.
- «توقف»: ارسال را قطع می‌کند و اتصال‌ها بسته می‌شوند. بستن فرم نیز همین کار را می‌کند. درخواست اتصال یا پاسخ معطل حداکثر حدود ۳ ثانیه timeout دارد.

Connected تعداد اتصال‌های دارای handshake موفق، ACK records تعداد رکوردهای تاییدشده توسط گیرنده و Errors تعداد خطاهای همین اجراست. هنگام شروع مجدد شمارنده رکورد و خطا صفر می‌شود. خطاها پایین فرم دیده می‌شوند؛ در صورت خطای شبکه، دستگاه‌های فعال دوباره اتصال را امتحان می‌کنند.

همه شناسه‌ها ساختگی هستند و موقعیت GPS نمونه معتبر نیست. timestamp هر ارسال UTC فعلی است و CRC دوباره محاسبه می‌شود. این ابزار حرکت واقعی، مسیر یا تله‌متری سنسور تولید نمی‌کند. اگر allowlist گیرنده فعال است، باید شناسه‌های ساختگی تست را مجاز کنید؛ صرفاً برای محیط آزمایش. شناسه‌های دستگاه‌ها از `000000000000000` به‌ترتیب زیاد می‌شوند.

سرویس گیرنده در حالت پیش‌فرض اتصال بدون داده را پس از ۱۸۰ ثانیه می‌بندد. برای تست فاصله‌های طولانی‌تر، timeout گیرنده را متناسب با سناریو تنظیم کنید؛ وگرنه اتصال مجدد ممکن است در شمارنده خطا دیده شود. افزایش تعداد و کاهش فاصله ارسال باعث رشد سریع فایل‌های capture می‌شود.

فرمان خطی قبلی بدون تغییر باقی است:

```powershell
py -3 tools/GpsSimulator/simulate.py --host 127.0.0.1 --port 5027 --fragment
```

تست خودکار هسته شبیه‌ساز:

```powershell
py -3 -m unittest discover -s tools/GpsSimulator -p test_engine.py -v
```
